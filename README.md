# diff-supa

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run index.ts
```

This project was created using `bun init` in bun v1.2.22. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.

```bash
 bun run pg-diff -f config.json -c GobernAI.sync.config {{name}}
```

| Aplicar migracion "falta"

```bash
bun run dev sync
```
